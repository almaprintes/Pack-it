# PACK IT! — Item assets

Sube aquí los objetos finales del juego en WebP con transparencia.

## Convención
- Fondo transparente.
- Vista cenital 90°.
- Iluminación coherente con la caja.
- El asset visual no define la colisión: cada objeto conserva una huella de cuadrícula independiente.
- Nombres en minúsculas y con guiones.

## Primeros assets
- `tshirt-folded-blue.webp` — camiseta doblada azul — huella inicial: 3×3.
- `book-red.webp` — libro rojo — huella prevista: 2×3.
- `sneaker.webp` — zapatilla — huella por definir tras generar el asset.
- `mug.webp` — taza — huella por definir tras generar el asset.
- `camera.webp` — cámara — huella por definir tras generar el asset.

La geometría final se ajustará a la huella visual de cada asset manteniendo una escala física coherente entre objetos.
